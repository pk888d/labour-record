- [2026-07-05] [claude] — Fixed: gross wage calculation understated, and "days worked" totals disagreeing between the Wage Register/Wage Slip and the Muster Roll for the same employee/cycle. Root cause: `calculateAttendanceTotals` computed `wageDays = daysWorked + leaveDays`, excluding paid holiday/weekly-off (`H`) marks — but paid holidays count toward wages. This undercounted `wageDays` both (a) fed the wage-proration formula in the form-entry page, shrinking gross wages for anyone with any holiday/off day in the cycle, and (b) got persisted as `AttendanceRecord.wageDays`, which the Wage Register/Wage Slip read, while the Muster Roll independently computed the (correct) `worked + holiday + leave` total — causing the two documents to print different day totals for the same employee. Fixed the shared calculator to include holiday days: `wageDays = daysWorked + leaveDays + holidayDays`, matching the Muster Roll's formula.
  Files: src/domain/calculations/attendance-calculator.ts, src/domain/calculations/attendance-calculator.test.ts. DB: none. Tests: `tsc --noEmit` clean (1 pre-existing unrelated e2e error), `vitest run` 92/92 passed, `npm run build` success.
